# О проекте
Веб-интерфейс, состоящий из двух основных блоков: интерактивной карты (слева) и панели списка объектов с элементами управления (справа). Интерфейс поддерживает динамическое отображение маркеров, их визуальную дифференциацию по цветам, построение линий между связанными объектами, фильтрацию видимости и полный сброс состояния.

# Архитектура и компоненты интерфейса
Интерактивная карта (Левая панель, ~70% ширины экрана)

•	Отображение маркеров: На карте рендерятся гео-точки на основе входного массива данных (JSON).

•	Цвета маркеров:

- Маркеры с разными значениями поля title имеют разный цвет.

-	Маркеры с одинаковым значениеми поля title окрашены в один и тот же цвет.

-	Цвета генерируются через специальную хэш-формулу **FNV-1a (Fowler–Noll–Vo hash)**

•	Логика связей (Линии):

-	Если у двух или более маркеров совпадает значение поля title, между ними на карте строится линия (Polyline).

-	Цвет линии совпадают с цветом маркеров этой группы.

-	Если точек с одинаковым title больше двух, они соединяются последовательно в порядке возрастания их id (или индекса) в исходном массиве данных.

•	Интерактивность: При клике на маркер открывается попап с информацией (title и description).

# Боковая панель 
Панель имеет фиксированную ширину и независимый вертикальный скролл. Она делится на две зоны:

Верхняя зона (Блок управления):

•	Кнопка «Очистить»:

-	Скрывает абсолютно все маркеры и линии с карты.

-	Полностью очищает нижнюю зону боковой панели.

•	Кнопка «Поиск»:

-	Заново отображает все маркеры и линии связи на карте.

-	Возвращает все карточки объектов в боковую панель.

-	Все чекбоксы на карточках снова становятся активными (включенными).

-	Карта плавно центрируется на исходную позицию (оптимальный масштаб для показа всех точек).

Нижняя зона (Список карточек объектов):

•	Каждая карточка содержит:

-	Чекбокс управления видимостью (по умолчанию активен).

-	Визуальный индикатор цвета (например, цветная точечка или иконка, цвет которой совпадает с цветом этого маркера на карте).

-	Заголовок (title).

-	Описание (description).

•	Взаимодействие: Клик по телу карточки (мимо самого чекбокса) плавно центрирует карту на данном маркере и автоматически открывает его попап.

# Функциональные требования и реактивность
•	Управление видимостью (Чекбоксы):

-	Снятие чекбокса на карточке мгновенно скрывает соответствующий маркер с карты.

-	Динамическое обновление связей: Если один из связанных маркеров (с общим title) скрывается чекбоксом, линия связи до него должна исчезнуть. Между оставшимися видимыми маркерами этой группы линия перестраивается заново (если видимых точек с этим title осталось ≥ 2). Если остается только одна видимая точка группы, линия исчезает полностью.
